## Files in this repository that are not MIT

The MIT license covers the code written for this repository. Some files are
derived from OpenZFS, and they keep OpenZFS's license, the Common Development
and Distribution License 1.0 (CDDL-1.0). The CDDL is a file-level copyleft
license: these files stay CDDL-1.0 when they are distributed, together with
their source, and the rest of the repository stays MIT.

| Path | License | Why |
|---|---|---|
| `src/native/ZfsWriteCore/zfs_write_core.c` | CDDL-1.0 | Ports of the OpenZFS Linux ZPL (`zfs_dir.c`, `zfs_znode.c`, `zfs_vnops_os.c`). The file carries `SPDX-License-Identifier: CDDL-1.0`. |
| `patches/openzfs-windows/*.patch` | CDDL-1.0 | Modifications to OpenZFS / OpenZFS-on-Windows files, all of which are CDDL-1.0. |
| `OpenZFS/` (submodule) | CDDL-1.0, with per-file exceptions | Upstream OpenZFS `zfs-2.4.4`, unmodified. |
| `third_party/openzfs-windows/` (submodule) | CDDL-1.0, with per-file exceptions | OpenZFS on Windows `zfswin-2.4.1rc17`, with the patches above applied at build time. |
| `third_party/zlib-1.3.2/` | zlib | Unmodified zlib release. |

The read-only reader's LZJB and ZLE decoders in `src/native/ZfsCore/zfs_core.c`
were written for this repository from the on-disk formats. They are MIT.

The test fixture manifests in `tests/fixtures/` are MIT. The pool images they
describe are generated by the fixture tools and are not committed.

## Notes for binary distributions

- **Source availability.** A binary that contains CDDL-1.0 code, such as the
  driver, the tools or `zfs-write-core`, must be distributed with, or with an
  offer of, the source of those CDDL files, including
  `patches/openzfs-windows/`.
- **License notices.** Release packages must include this file, the CDDL-1.0
  text, and the notices of every component in the table above that is
  compiled into them (step 17 generates an SBOM for this).
- **C runtime.** Debug builds link the Microsoft debug C runtime, which is not
  redistributable. Only Release builds may be distributed.
