# Failures the VM suites report on every run, so CI (Invoke-CiSuite.ps1)
# does not fail on them.  One regular expression per line, matched against a
# whole failure line ("<check> <failed items>"); "platform/edition: regex"
# limits it to one suite (wildcards allowed).  A new failure, or a known one
# with an item not listed here, fails the job.  Remove a line once it is fixed.

# Upstream openzfsonwindows gaps (kernel driver): ACL enforcement and old
# snapshot content/ACLs/streams through .zfs.
x64/kernel: ACLs, streams and \.zfs ((user-cannot-write-read-only-grant|user-denied-by-deny-ace|snapshot-old-content|snapshot-acl|snapshot-stream)(, )?)+
arm64/kernel: filesystem ((user-cannot-write-read-only-grant|user-denied-by-deny-ace|snapshot-old-content|snapshot-acl|snapshot-stream)(, )?)+
x64/kernel: user-mode pool read by the kernel driver snapshot-f1
arm64/kernel: crosscheck: ARM64 user-mode pool read by the kernel driver snapshot-f1
# Intermittent .zfs snapshot read right after creation (kernel, Debug).
arm64/kernel: cli snapshot-s1-content
