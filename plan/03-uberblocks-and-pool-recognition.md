# Step 03 — Pool recognition and uberblock selection

Status: `planned`

Objective: recognize genuine OpenZFS raw vdev images and select a valid
uberblock without writing to the image.

Implementation:

- decode label nvlist with bounds and endian checks;
- validate pool and vdev GUIDs, ashift, topology, and feature flags;
- scan uberblock rings and select the highest valid transaction group;
- verify uberblock checksums and reject unsupported metadata safely;
- expose pool identity and unsupported-feature diagnostics in the C ABI.

Evidence: fixtures generated by official OpenZFS tools; selected uberblock
matches independent upstream inspection; image hash unchanged.

Commit: `native: recognize pools and validate uberblocks`
