OpenZFS for Windows

Kernel-driver edition: the OpenZFS file system driver, the ZfsWinBroker service, zfswin.exe and the ZfsWin PowerShell module.

Test-signed preview. The driver loads only with test signing on (bcdedit /set testsigning on, Secure Boot off) and the project certificate trusted. Use it on test machines only. Make sure a disk does not hold data you need before you give it to ZFS.

The graphical tool

Start OpenZFS for Windows from the Start menu (ZfsWinGui.exe). It shows:

  • pool health, capacity and devices;
  • scrubs;
  • compression, deduplication and sync per dataset;
  • adding and removing mirror disks, read caches (L2ARC) and write logs (SLOG).

It needs the .NET 10 Desktop Runtime; Windows offers it on first start if it is missing. Everything below can also be done from a terminal.

1. Check the installation

Open a new terminal, so the updated PATH applies, and run:

zfswin version
sc query OpenZFS
sc query ZfsWinBroker

Read-only commands work for every user. Commands that change something need a terminal opened with Run as administrator.

2. Create a pool

Identify the disk first. Creating a pool erases the disk.

Get-Disk                                   # note the number of the empty disk, e.g. 2
zfswin pool create tank \\?\PhysicalDrive2 -O compression=lz4 --yes
zfswin pool create tank --mirror \\?\PhysicalDrive2 \\?\PhysicalDrive3 --yes   # two disks

To experiment without a disk, use a file (it must already exist at full size):

fsutil file createnew D:\pools\disk1.img 1073741824
zfswin pool create lab D:\pools\disk1.img --yes

Without --yes, every destructive command stops with exit code 6 and changes nothing.

3. Datasets, mounting and files

zfswin dataset create tank/home -o compression=zstd
zfswin mount list                          # where each dataset is mounted (drive letter or folder)
zfswin dataset set tank/home atime=off com.example:owner=me
zfswin dataset get tank/home compression used available

Use the mounted drive or folder like any other: Explorer, robocopy, applications.

4. Snapshots

zfswin snapshot create tank/home@before-upgrade
zfswin snapshot list tank/home
zfswin snapshot destroy tank/home@before-upgrade --yes

Snapshot contents are readable under <mountpoint>\.zfs\snapshot\<name>.

5. Health, scrub, mirrors

zfswin pool status tank
zfswin scrub start tank        # verifies every block; repairs from redundancy
zfswin scrub status tank
zfswin vdev attach tank \\?\PhysicalDrive2 \\?\PhysicalDrive3 --yes   # turn a single disk into a mirror
zfswin vdev add-cache tank \\?\PhysicalDrive4 --yes                    # read cache (L2ARC) on an SSD
zfswin vdev add-log tank --mirror \\?\PhysicalDrive5 \\?\PhysicalDrive6 --yes   # write log (SLOG)
zfswin vdev remove tank \\?\PhysicalDrive4 --yes                        # remove a cache or log device

6. Move a pool to another computer

zfswin pool export tank        # on this computer
zfswin pool discover           # on the other one (Windows), then:
zfswin pool import tank

Linux, FreeBSD and macOS with OpenZFS 2.4 import the same pools with zpool import.

7. PowerShell

Import-Module ZfsWin
Get-ZfsPool
Get-ZfsDataset tank -Recurse
New-ZfsSnapshot tank/home@daily
Get-Command -Module ZfsWin     # all 26 cmdlets

Destructive cmdlets prompt for confirmation and support -WhatIf.

8. Upstream tools

zpool.exe, zfs.exe, zdb.exe and kstat.exe are in the same bin folder, for anything zfswin does not cover. Run them from an elevated terminal.

Exit codes

CodeMeaning
0success
1the ZFS command failed
2bad command line or argument
3not found
4access denied (run as administrator)

6--yes required
7timeout or cancelled
9busy

More

This folder contains licenses\, symbols\ (for crash-dump analysis) and VERSION.json. The full documentation, with the command reference, upgrade and uninstall steps, recovery and manual driver removal, is in the project repository under docs/. Events: Event Viewer > Windows Logs > Application, source ZfsWinBroker.

Uninstall in Settings > Apps. Setup refuses while pools are imported, and never deletes pool data.
